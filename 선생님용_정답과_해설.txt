=====================================================
 1929, 11월 3일의 함성 - 선생님용 정답과 해설
=====================================================
 대상: 중학생 / 제한 시간 45분 / 힌트 전체 3회 (+ 역사 퀴즈로 추가 힌트)
 흐름: 나주역(10.30) → 파출소 취조실 → 광주고보 기념식(11.3 아침) → 광주 시내(11.3 오후)
       → 독서회 아지트(11.10 밤) → 광주 밤거리(11.11 밤) → 광주고보(11.12 장날) → 엔딩
 주인공: 광주고보 2학년 독서회 막내(남학생)
 동료: 은희 - 광주여고보 학생, 소녀회 회원 (가상 인물, 박기옥과 같은 반이라는 설정)
 ※ 11월 3일과 12일 장면이 광주고보 안에서 일어나서, 주인공은 남학생 한 명으로 정했어요.
   대신 여학생 동료 은희가 거의 모든 장면을 함께 다닙니다.

■ 새로 생긴 게임 방식
  · 빨간 칸 = 순사·선생님이 보는 곳. 그 안에 들어가면 들켜서 정해진 자리로 돌아감 (점수 깎임 없음)
  · 미션 = 제한 시간 안에 여러 사람에게 말 걸기 (쪽지 전하기, 행진 사람 모으기)
  · 타이밍 = 등사기 바늘이 초록 칸에 올 때 누르기
  · 사료 카드 8장 = 엔딩 기록에 "모은 사료 n/8"로 표시 (2장은 숨어 있어요)
  · 힌트 3번을 다 쓰면 H를 눌러 역사 퀴즈 → 맞히면 힌트 1개 더
  · 노란 화살표 이름표 = 지금 찾아갈 곳 / 화면 위 [전체 화면] 버튼

-----------------------------------------------------
1. 나주역 (1929년 10월 30일)   — 잠행
-----------------------------------------------------
 p1 순사 둘(플랫폼, 역 앞 광장)을 피해 증거 1개 + 증언 3개 모으기
   · 댕기: 플랫폼 가운데 바닥
   · 역무원: 개찰구 옆. 댕기를 먼저 가져와야 증언함
   · 광주여고보 학생: 플랫폼 왼쪽 벤치 옆
   · 역 앞 상인: 광장 왼쪽 좌판 앞
   · (사료 ①) 통학 열차 시간표: 플랫폼 오른쪽 게시판
   → 오른쪽 아래 파출소 문으로
 학습: 나주역 사건의 발단(일본인 학생의 희롱)과 일본 경찰의 편파적인 처리

-----------------------------------------------------
2. 파출소 취조실
-----------------------------------------------------
 p2 경위서 모순 (다이얼)  정답: 댕기 → ③ / 역무원 → ② / 상인 → ④
    ② '까닭 없이 먼저 때림' ↔ 괴롭힘에 맞서 따진 것   ③ '조용히 내렸다' ↔ 댕기   ④ '공평하게 말렸다' ↔ 조선 학생만 때림
 p3 서랍 자물쇠  정답: 1103
    단서: 메모 "서랍 번호 = 다음 경축일(월·일)" + 달력 11월 3일 명치절 동그라미 → (사료 ②)
 · 열쇠로 유치장 문 → 박준채 구출 → 오른쪽 아래 뒷문
 ※ 각색: 실제로 박준채는 경찰에게 맞고 나무람을 들었지만, '유치장 구출'은 게임을 위한 이야기입니다.

-----------------------------------------------------
3. 광주고보 명치절 기념식 (11월 3일 아침)   — 미션 + 잠행
-----------------------------------------------------
 p4 선생님 두 명의 시야를 피해 80초 안에 독서회 동지 5명에게 쪽지 전하기
    동지 위치(운동장 줄): 앞줄 왼쪽에서 2번째·7번째 / 가운데 줄 왼쪽에서 3번째 / 뒷줄 맨 왼쪽·오른쪽에서 2번째
    → 기미가요: '입을 꾹 다문다' (다른 선택도 결국 침묵으로 이어짐) → (사료 ③)
 · (사료 ④ 숨김) 왼쪽 위 숙직실 앞에서 창틀 조사 → 성진회 수첩
 · 교문으로 나가 시내로
 학습: 11월 3일 = 메이지 일왕 생일(명치절), 음력 10월 3일 개천절.
       광주고보 학생들의 기미가요 거부, 신사 참배 거부
 ※ 각색: 쪽지를 돌린 장면은 게임용 연출입니다.

-----------------------------------------------------
4. 광주 시내 (11월 3일 오후)   — 미션 + 행진
-----------------------------------------------------
 p6 광주일보 기사 바로잡기 (다이얼)  정답: 일본인 학생 / 여학생을 괴롭혀서 / 일본 학생 편을 들었다  → (사료 ⑤)
    학습: 편파 보도, 학생들이 광주일보에 몰려가 항의(윤전기에 모래를 끼얹었다고 전해짐)
 p7 장재성(큰길) → 110초 안에 학생·시민 6명에게 말 걸기 (장터 3명, 충장로 3명) → 사람들이 따라옴
    → 동문다리(오른쪽 위)로 가면 순사들이 막음 → 충장로를 지나 도청 앞 광장 가운데로 → (사료 ⑥)
    학습: 동문다리에서 막히자 충장로를 거쳐 도청 앞까지 행진. "조선 독립 만세", "식민지 노예 교육 철폐"
          체포된 학생은 조선인이 훨씬 많았고, 학교는 휴교
 ※ 게임 지도는 실제 광주 거리 배치와 다릅니다. (장소 이름과 행진 순서만 맞춤)

-----------------------------------------------------
5. 독서회 비밀 아지트 (11월 10일 밤)   — 암호 + 타이밍
-----------------------------------------------------
 · 농업학교 동지 대화 → 책장에서 『농업 개론』(3번째) → 금서
 · 들뜬 장판 → 구멍 뚫린 카드
 p8 회의록 (다이얼)  정답: 십이일 / 장날 / 종소리  (금서 37쪽에 카드를 대면 보이는 글자)
 · 격문 조각 3개: 벽장(오른쪽 위), 화로(오른쪽), 이불(오른쪽 아래)
 p9 등사기 앞 네 가지 요구 (다이얼)  정답: 석방 / 철폐 / 금지 / 자유
 p10 등사기 타이밍: 10번 성공(1,000장), 실수 3번까지  → (사료 ⑦)
 학습: 성진회(1926)·독서회, 장날을 거사일로 정한 까닭, 격문의 요구
 ※ 각색: 금서 문장·암호 카드·격문 조각은 게임을 위해 만든 것입니다. 네 가지 요구는 실제 격문의 요구를 쉽게 줄였습니다.
   실제로 격문은 11월 10~11일 무렵 비밀리에 등사(인쇄)되었습니다.

-----------------------------------------------------
6. 광주 밤거리 (11월 11일 밤)   — 잠행
-----------------------------------------------------
 p11 등불 든 순사 4명을 피해 광주천 건너 세 학교 교문 옆에 격문 두기
     광주농업학교(동문다리 건너 위쪽), 광주여고보(가운데, 사료 ⑧), 광주사범학교(남쪽 다리 건너 아래쪽)
     → 아지트로 돌아가기
     요령: 냇가 길을 오르내리는 순사가 멀어졌을 때 다리를 건너고, 큰길보다 풀밭으로
 ※ 각색: 다른 학교로 격문을 전하는 밤 장면은 게임을 위한 이야기입니다.

-----------------------------------------------------
7. 광주고보 (11월 12일 장날)   — 협동 + 잠행
-----------------------------------------------------
 p12 운동장 동쪽 학교 종 치기(신호) → 학생들이 쏟아져 나오고 감시 시작
     동지 3명에게 말 걸기: 왼쪽 나무 옆 독서회 동지, 오른쪽 농업학교 학생, 오른쪽 아래 박준채
     → 교문을 지키던 셋이 사라지면, 순찰 선생님을 피해 교문으로
     → 엔딩: 행진 → 전국 확산 지도 → 학생독립운동기념일 → 정리 카드 5장 → 후기 링크
 학습: 11월 12일 2차 시위(광주고보·광주농업학교 중심, 수백 명 체포),
       1930년 3월까지 194개 학교·5만 4천여 명 참여(320개 학교라는 기록도 있음),
       3·1 운동 이후 최대의 민족 운동, 신간회의 진상 조사
 ※ 각색: 종을 쳐서 신호를 보낸 장면, 동지들이 감시를 따돌리는 장면, 은희가 시위에 합류하는 장면은 게임용입니다.
   (실제로 학생들은 수업 중 신호에 맞춰 일제히 교문을 나섰다고 전해집니다.)

-----------------------------------------------------
 힌트 (게임 전체 3회, 아직 안 푼 첫 퍼즐의 힌트) / 역사 퀴즈 6문항
-----------------------------------------------------
  1 시작이 된 사건이 일어난 곳 → 나주역
  2 1929년 11월 3일은 일본에게 → 메이지 일왕의 생일(명치절)
  3 학생 비밀 모임 → 독서회
  4 11월 12일을 장날로 고른 까닭 → 사람이 많이 모이니까
  5 어떤 운동 이후 최대의 민족 운동 → 3·1 운동
  6 11월 3일은 오늘날 → 학생독립운동기념일

 사료 카드 8장
-----------------------------------------------------
  ① 통학 열차와 나주역 (나주역 시간표, 숨김에 가까움)   ② 나주역 사건과 편파 수사 (서랍)
  ③ 명치절 기념식 (쪽지 미션 뒤)                         ④ 성진회와 독서회 (숙직실 창틀, 숨김)
  ⑤ 광주일보의 거짓 보도 (기사 바로잡기)                 ⑥ 11월 3일의 함성 (도청 앞)
  ⑦ 격문과 11월 12일 (등사기)                            ⑧ 광주여고보 소녀회 (밤 배달)

-----------------------------------------------------
 등장인물
-----------------------------------------------------
  실존 인물: 박준채(광주고보 2학년), 박기옥·이광춘(광주여고보, 이름만 등장), 장재성(독서회 중앙부 책임비서)
  가상 인물: 주인공, 은희, 독서회 동지들, 역무원·상인 등 시민, 순사, 일본인 교장·선생
  ※ 장재성의 대사는 게임을 위해 지은 것입니다.
